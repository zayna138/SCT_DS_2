# SCT_DS_2 - Titanic Data Analysis

## Objective
Perform Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
Titanic passenger dataset in CSV format.

## Analysis Performed
- Data inspection
- Missing value analysis
- Survival count visualization
- Age distribution analysis

## Visualizations
1. Survival Count Bar Chart
2. Age Distribution Histogram

## Outcome
Learned basic data cleaning, exploratory data analysis, and data visualization techniques using Python.

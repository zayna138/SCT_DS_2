# SCT_DS_2 - Titanic Dataset EDA

## Objective

Perform data cleaning and exploratory data analysis (EDA) on the Titanic dataset.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Description

This project explores the Titanic dataset to identify patterns, relationships, and trends through data analysis and visualization.

## Features

* Data cleaning
* Handling missing values
* Exploratory Data Analysis
* Correlation analysis
* Visualizations and insights

## Dataset

Titanic Dataset from Kaggle.

## Learning Outcomes

* Data preprocessing techniques
* Exploratory data analysis
* Feature relationship analysis
* Visualization skills
